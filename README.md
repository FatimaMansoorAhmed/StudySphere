# 📚 Study Notes Dashboard

A modern, responsive full-stack web application designed for students and professionals to manage, organize, and read study notes seamlessly. Built with **React**, **Tailwind CSS**, and a **Node.js/Express REST API**.

---

## ✨ Features

- 🔐 **User Authentication**: Secure access to create, update, and delete notes.
- 🎨 **Category Badging**: Categorize notes dynamically (*Programming, AI, Mathematics, Physics, etc.*) with sleek color coding.
- 📐 **Clean Grid Layout**: Standardized card layout with automatic line-truncation to keep the dashboard neat.
- 📖 **Read More Modal**: Full-screen interactive popup dialog to read detailed notes with clean scrollability.
- ✏️ **Full CRUD Operations**: Create, view, update, and delete notes effortlessly.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile views.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (Vite / CRA)
- **Tailwind CSS** (Styling & Layout design)
- **Axios** (API Requests)

### Backend 
- **Node.js** & **Express.js**
- **MongoDB** 
- **JSON Web Tokens (JWT)** (Authentication)
